# Splat library

Drop Gaussian splat captures here (`.ply`, `.spz`, `.splat`, `.ksplat`,
`.sog`) and reload the demo: each one appears in the Scene dropdown, named
after its file (`garden_v2.splat` shows as "Garden v2"). `[` and `]` step
through them.

The files are git-ignored because they are large. Free samples to start with:

- https://huggingface.co/cakewalk/splat-data/resolve/main/plush.splat (8.6 MB)
- https://huggingface.co/cakewalk/splat-data/resolve/main/nike.splat (8.3 MB)
- https://huggingface.co/cakewalk/splat-data/resolve/main/train.splat (31 MB)
